## Natureza da apresentação

O HTML contém simulações hipotéticas estáticas controladas por JavaScript. Ele não chama modelos, não envia dados para o backend do Coxinh.IA e não gera imagens reais. A identidade textual e paleta seguem a documentação atual; o arquivo PNG do logotipo oficial não está incorporado. O objetivo é ilustrar os conceitos, sem substituir a interface de produção.
